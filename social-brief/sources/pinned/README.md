# Pinned articles

Save today's articles here as `.txt` or `.md` before you start the agent.

Pinning is the whole point. The agent never reaches the network, so what is
in this folder is exactly what it can see, and you chose every file in it.
That is your context boundary and your attack surface in one place.

A worked example is in `example-2026-11-07-kev-php.md`. Delete it when you
put your own in.
