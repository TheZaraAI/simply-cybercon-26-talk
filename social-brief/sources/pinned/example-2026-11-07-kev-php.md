CVE-2026-109618 was added to the Known Exploited Vulnerabilities catalog.
Affected product is PHP Group PHP 8.2.12. The entry notes known use in
ransomware campaigns. The remediation due date for federal civilian agencies
was 2026-10-29.

The underlying flaw allows an unauthenticated attacker to execute code by
sending a crafted request to an exposed endpoint. A vendor patch has been
available since 2023.
